# Overlay Right Panel Text Inventory — 2026-10-08

## Scope and method

Read-only inventory of the current working-tree production render path for the right column: the localized `Runtime` heading (shown as **Поточний стан** in Ukrainian), `Viewport Aspect`, `Camera Integration`, and the collapsed/expanded `Camera State` tree. This report does not change source, catalogs, contracts, build outputs, or runtime state. It records the checked-out code as of 2026-10-08; this workspace already contains extensive user changes, so findings describe that working tree and are not a clean-HEAD comparison.

The right column is rendered by `OverlayRenderer::Render` in `src/overlay/renderer_runtime.cpp`. It reads `OverlaySemanticSnapshot` through `GetOverlaySemanticSnapshot`; `ReadOverlaySemanticSnapshot` in `src/plugin/runtime.cpp` copies authoritative camera snapshot and transition-boundary facts and reads current client viewport. `ProjectCameraIntegration` in `src/overlay/camera_integration.cpp` derives summary comparison/preview fields from those facts. `DrawCameraStateView` in `src/overlay/camera_state_view.cpp` renders the diagnostic tree, also using that projection for the four canonical FOV facts. The expanded tree is hidden until the `Camera State` tree node is opened. The grid/table labels appear left and values right, but some summary status/detail paragraphs and unavailable-state notices are outside those tables.

`Tooltip` column below gives the complete English/base tooltip text. `None` means no tooltip is attached in this render path. “Localized now?” distinguishes calls routed through the localization manager from literals/enum formatters that remain technical English. Catalog key availability is through the project localization inventory/parity contract; all listed localization keys are present in the English and Ukrainian catalogs. The desired English-only technical right panel is recorded as a future classification criterion only; it is not implemented here.
